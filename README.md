# AgentOS website

This is a small static website for the AgentOS Discord bot.

## Dashboard Access

- `ALLOWED_ROLE_IDS` controls the existing exam dashboard access.
- `AOS_ALLOWED_ROLE_IDS` controls the new AOS dashboard and AOS profile access.
- The site landing dashboard is now `dashboard.html`, with links out to `exams.html` and `aos-dashboard.html`.
